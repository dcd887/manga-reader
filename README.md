# 漫览 · 开源漫画阅读器

随时随地打开就能看漫画的 H5 阅读器。图源为 **MangaDex**（全球最大的开源漫画图源平台，官方开放 API，完全免费，中文 / 英文 / 日文漫画都有）。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 阅读器本体（单文件，无需安装任何依赖） |
| `worker.js` | 可选：Cloudflare Worker 代理，用于让手机 / 任何网络环境都能访问图源 |
| `README.md` | 本说明 |

## 功能

- 搜索漫画（支持中文 / 英文 / 日文原名）
- 语言过滤（中文 / 英文 / 全部）
- 漫画详情：作者、简介、更新进度、章节列表
- 阅读器：翻页 / 键盘 ← → / 手机滑动翻页
- 自动记住每部漫画的阅读进度（浏览器本地保存，下次打开直接"继续阅读"）

## 方式一：电脑本机直接用（最简单）

```bash
cd 漫画阅读器
python3 -m http.server 8723
```

浏览器打开 `http://localhost:8723` 即可。图源对 localhost 放行，无需代理。

## 方式二：部署到 GitHub Pages（推荐，随时随地）

1. 把 `index.html` 上传到你的 GitHub 仓库（仓库名随意，比如 `manga-reader`），勾选启用 GitHub Pages（Settings → Pages → Deploy from branch → main）
2. 此时页面地址是 `https://你的用户名.github.io/manga-reader/`，但直接打开图源会被浏览器拦截，需要配合下面的免费代理
3. 部署 Cloudflare Worker 代理（免费，约 3 分钟）：
   - 打开 https://dash.cloudflare.com 注册 / 登录（免费账号即可）
   - 左侧 Workers & Pages → 创建应用程序 → 创建 Worker
   - 删除模板代码，把 `worker.js` 的内容整段粘贴进去
   - 保存并部署，得到地址：`https://你的代理名.workers.dev`
4. 打开你的阅读器页面 → 点右上角 **⚙** → 填入 `https://你的代理名.workers.dev` → 保存
5. 完成。之后手机、宿舍、任何地方打开这个链接都能看漫画

> 原理：浏览器直接请求 MangaDex API 时，图源只放行 localhost 和官方域名；Worker 代理转发请求并放开跨域，任何网址就都能用了。

## 方式三：手机和电脑同一 WiFi（不部署，临时用）

电脑跑方式一的本地服务后，手机浏览器访问 `http://电脑局域网IP:8723`。
注意：此时图源会拦截跨域，需要先在电脑浏览器上把代理填好……实际上局域网 IP 不被图源放行，所以此方式**必须配合代理**才能看图。推荐直接用方式二。

## 说明与边界

- **图源范围**：MangaDex 是全社区上传的开放平台，中文区现有约 760 部作品、多语言作品数万部。热门商业漫画（如《海贼王》《我独自升级》）因版权方要求已下架，这是开放图源的客观边界。
- **《炎之束缚》**：此部为汉化组作品，MangaDex 上搜不到（已验证），看这部请继续用你的蓝奏云网盘（56 话已全部转存，装蓝奏云 App 即可随时看）。
- 阅读器本身完全合规：只调用 MangaDex 官方开放 API，不抓取任何盗版源。
- 图片加载失败时点击"下一页 / 上一页"重进即可，偶尔是图源 CDN 节点波动。

## 疑难排查

| 现象 | 处理 |
|---|---|
| 主页一直"加载失败" | 检查网络；若是 GitHub Pages 打开的，确认已配置代理（⚙） |
| 搜索不到中文作品 | 切到"中文"过滤，或用日文 / 英文原名搜索 |
| 某个章节图片不显示 | 刷新页面重新进入该章节 |
